## 运行方式与环境

```bash
.venv/Scripts/python.exe -m week08.vector_lab
```

以下数字直接复制自上述命令的终端输出（2026-11-26 实跑）。
向量由本地 `HashEmbedding(dim=16, normalize=True)` 生成，未使用任何外部服务或业务数据。

## 实测结果

### 1. 三种相似度（查询相同）

| 度量 | Top-3 |
| --- | --- |
| cosine | c002 / c005 / c004 |
| dot | c002 / c005 / c004 |
| euclidean | c002 / c005 / c004 |

三者一致是**预期结果**：向量已归一化，cosine 与 dot 等价；欧氏距离与
余弦相似度在该数据上给出相同序。这说明度量口径统一，而不是说明算法"都一样"。

### 2. 标量过滤

- 不过滤：10 条全部命中。
- `dept_id=ops` 且 `valid_until > 2026-11-26`：5 条（c002 / c005 / c001 / c003 / c010）。

过期的 c006 与其他部门的 c004/c007/c008/c009 均被排除，且过滤发生在打分之前。

### 3. 持久化重载

保存前 10 条 / 重载后 10 条 / Top-3 一致：`True`。

### 4. 召回基准（候选子集模拟 ANN）

| 候选占比 | recall@3 |
| --- | ---: |
| 30% | 33% |
| 60% | 100% |
| 100% | 100% |

候选只有 30% 时丢失了精确 Top-3 中的两个，说明调小 ANN 搜索范围确实会掉召回；
100% 是精确基线，必须作为对照点保留。

## 结论（面试可用）

- 向量检索就是在熟悉的 RDBMS 上做近邻查询，RBAC 与有效期字段要在建表阶段进入。
- 度量口径要统一成"越大越相关"，归一化后 cosine 与 dot 排序一致。
- 召回率必须相对暴力精确结果测量，ef_search / probes 的取舍才有依据。
