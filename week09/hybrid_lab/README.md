# 混合检索动手实验室（week09/hybrid_lab）

> 教学模拟电网/运维知识库，全部数据在本地构造，不接真实系统、不需要 API Key。

## 一、这个实验室回答什么问题

纯向量检索对 `SGCC-4012`、`ERR_4012` 这类专有名词有系统性盲区——语义空间不保证
罕见标识符彼此可分。BM25 恰好相反：字面精确匹配强，但同义问法召不回。
本实验用同一批查询对比"纯向量"与"BM25 + 向量 RRF 融合"，给出可复现的数字。

## 二、运行方式

```bash
python -m week09.hybrid_lab
python -m week09.hybrid_lab > week09/hybrid_lab/REPORT.md
```

## 三、文件职责

| 文件 | 职责 |
| --- | --- |
| `corpus.py` | 15 条模拟中文 chunk，含型号、错误码、部门与失效条目 |
| `queries.py` | 10 条查询：普通 3 / 专名 4 / 带过滤 3，附相关 chunk_id |
| `__main__.py` | 逐条跑两路召回，输出 Recall@1 对比表与分组均值 |
| `REPORT.md` | 程序真实运行输出，不手写、不伪造 |

## 四、实验设计

- **同条件**：两路方法用同一 `dept` / `valid` 前置过滤，同一个 `top_k=1`。
- **同语料**：15 条 chunk 固定，chunk_id 稳定。
- **融合**：`HybridRetriever` 默认 RRF（k=60），不做归一化、不引入权重调参。
- **指标**：只看 Recall@1——教学语料小，K 越大数据差异越容易被抹平；
  完整评测体系留到第 12 周，rerank 留到第 10 周。

## 五、预期观察

- 普通语义问题：两路差距不大，向量路偶有优势。
- 专名问题：混合路靠 BM25 补位，Recall 明显更高。
- 带过滤问题：前置过滤保证失效/越权文档不占 Top-1 名额。

真实结果见 [`REPORT.md`](REPORT.md)。
