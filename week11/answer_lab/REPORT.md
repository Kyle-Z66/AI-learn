# 第 11 周 · 生成可靠性实验报告

> 数据来源：本仓库 `python -m week11.answer_lab` 的实际输出抄录（本地确定性 FakeGenerator）。
> 这是**教学样例**：上下文与问题均为虚构的运维知识片段，不是任何真实业务数据或线上指标。

## 一、运行命令与环境

```bash
python -m week11.answer_lab
```

- 生成侧：`FakeGenerator(temperature=0.1)`，答案逐字来自上下文，带 `[n]` 引用；
- 上下文：`build_context(chunks, max_tokens=1000)`，2 个片段全部入选，`truncated=False`；
- 无网络、无 API Key、无随机种子依赖。

## 二、逐例结果（真实输出）

| 类别 | 拒答 | 守卫通过 | 失败项 | 判定 |
| --- | --- | --- | --- | --- |
| 相关 | False | True | `()` | 按预期放行 |
| 不相关 | True | False | `('relevance', 'post_check_skipped')` | 符合预期（拒答） |
| 数字幻觉 | False | False | `('500',)` | 按预期拦下幻觉 |
| 实体幻觉 | False | False | `('李四',)` | 按预期拦下幻觉 |

自检结果：**通过**（4/4 用例判定符合预期，进程退出码 0）。

### 关键输出片段

- 相关：答案 `[1] 系统 cyclone 的严重级别为 2 级，影响 30 名用户；[2] 负责人为张伟……`，
  引用可回溯到 `DOC-001#p3`、`DOC-001#p4`。
- 不相关：`信息不足，无法基于给定上下文回答：检索结果与问题不相关`，
  预检失败后跳过后校验，不产生任何编造内容。
- 数字幻觉：把答案中的 `30` 替换为 `500`，后校验失败项恰为 `('500',)`。
- 实体幻觉：把答案中的 `张伟` 替换为 `李四`，指定实体清单下失败项为 `('李四',)`。

## 三、结论与边界

1. 引用编号从上下文组装阶段分配，答案里的 `[1][2]` 能 1:1 映射回 doc_id / 标题 / 页码。
2. 预检挡住"检索结果与问题无关"，后校验挡住"答案编造数字/实体"，两者失败项可分别观测。
3. 低温度（0.1）在本实验中只作为可复现参数记录；它降低随机性，**不保证事实正确**。
4. 边界：本实验没有评测指标与 golden set（第 12 周内容），也没有真实检索排序；
   守卫通过只说明"答案中的可核验声明都在上下文里"，不代表上下文本身正确。
